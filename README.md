# Volpi

Volpi is a desktop app for researchers. Read and highlight PDFs, write linked notes, check
data and write papers with citations. Each project is a plain folder on your computer, with
no account and no cloud.

This repository hosts the Volpi installers. Volpi's source code is not public.

## Download

The newest version is always on the [Releases page](https://github.com/Phantom-Con-Artist/Volpi-Releases/releases/latest).
Each download is a zip with the installer, install steps, the changelog and the licence.

| Your computer | Download |
|---|---|
| Windows 10 or 11 (64-bit) | [Volpi-Windows-x64.zip](https://github.com/Phantom-Con-Artist/Volpi-Releases/releases/latest/download/Volpi-Windows-x64.zip) |
| macOS, Apple Silicon (M1 and later) | [Volpi-macOS-AppleSilicon.zip](https://github.com/Phantom-Con-Artist/Volpi-Releases/releases/latest/download/Volpi-macOS-AppleSilicon.zip) |
| macOS, Intel | [Volpi-macOS-Intel.zip](https://github.com/Phantom-Con-Artist/Volpi-Releases/releases/latest/download/Volpi-macOS-Intel.zip) |
| Linux (64-bit): Debian, Ubuntu, Fedora, openSUSE and similar | [Volpi-Linux-x64.zip](https://github.com/Phantom-Con-Artist/Volpi-Releases/releases/latest/download/Volpi-Linux-x64.zip) |

Not sure which Mac you have? Apple menu, About This Mac: "Chip" means Apple Silicon,
"Processor" means Intel.

Earlier versions stay on the [Releases page](https://github.com/Phantom-Con-Artist/Volpi-Releases/releases),
named with their version (for example `Volpi-0.1.0-Windows-x64.zip`).
